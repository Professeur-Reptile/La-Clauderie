DPS maximal par classe

Le meilleur DPS soutenu simulé pour chaque classe, avec le build DPS recommandé sur la page Builds et un équipement BiS complet.

À lire avant de comparer : une seule spé DPS est comparée par classe : le premier build DPS affiché sur la page Builds. Ce sont des résultats contrôlés du simulateur, pas une promesse pour tous les combats. Le modèle suppose le niveau 20, le BiS complet, une rotation propre sur une seule cible et Nythraxis en normal. Les déplacements, les mécaniques, le temps de réaction et les erreurs font baisser le résultat.
