Patch notes v0.39.1

01The desktop app could no longer enter the world

One clean break, and only one: on the installed app (Windows, macOS, Linux), world entry stopped at the loading screen. The same account, the same character and the same realm worked fine in a browser or on a phone.

What you saw, and who was affected Fixed

On the desktop app under v0.39.0, world entry never completed. Browser and mobile were never affected: they do not enforce the security rule involved. If you play on the website, none of this reached you.

See details

A security rule that was too strict Behind the scenes

The app protects itself with a list of what it is allowed to load. The game's texture decompressor starts by reading itself from an internal address — a case the list had missed. The result: refused, and 170 3D models impossible to display. The missing permission has been added.

See details

What you need to do In practice

  • On the desktop app: install v0.39.1, and world entry works again.
  • Nothing to tweak, no cache to clear, no setting to change.
  • In a browser or on mobile: nothing to do, you were never affected.

Two guards added Behind the scenes

  • An automatic check now ties the permission list to the decompressor's actual code: if either moves without the other, it fails before release.
  • A second test really enters the world, in a browser, under the desktop app's own list.
  • Both were verified red before the fix and green after — they are not for show.

No added risk Security

  • The permission added only covers data the app already carries inside itself: it is not an internet address.
  • So it opens no door to the outside.
  • The same permission already existed, for the same reason, on the image side.

02And nothing else

This is a hotfix in the strict sense. Everything v0.39.0 brought the day before stays exactly where it was.

Nothing moves in the game Scope

  • No combat value: no spell, no talent, no mastery, no set.
  • No item, no mob, no quest, no zone.
  • No data migration: nothing to redo on your character.

The scenery has not changed Behind the scenes

  • The Fenbridge 3D models were re-stamped as part of the version bump.
  • Only their internal fingerprint moves: identical geometry and textures, identical size, no visible difference.
  • Same operation as in v0.38.4, for the same reason.

v0.39.0 still stands Reminder

  • Wildfang keeps Gorebite at level 8 and its three ranks of Redharvest.
  • The Last Keep and Dawnhold Castle stay walkable, floor plan included.
  • It is all laid out on the v0.39.0 page.
